# xaltarin-config

**Obtener un nuevo archivo `.ovpn`**:
   * Entrá a [VPN Gate](https://www.vpngate.net/en/) o al servicio de tu preferencia.
   * Buscá un servidor activo y descargá su archivo de configuración `.ovpn`.

**Reemplazar el contenido**:
   * Adentro de este repositorio, hacé clic sobre el archivo `perfil.ovpn`.
   * Tocá el ícono del **lápiz** (Edit this file) arriba a la derecha.
   * Borrá todo el texto viejo, abrí el nuevo archivo que descargaste con un bloc de notas, copialo completo y **pegalo** ahí adentro.

4. **Guardar los cambios (Commit)**:
   * Bajá hasta el fondo de la página.
   * En el título del commit, escribí una descripción breve (ej: `Actualizado servidor - Fecha - País`).
   * Hacé clic en el botón verde **Commit changes**.
